# Pointcloud Target Processing

A python package to extract target points from a pointcloud for lidar metrology studies.

## Architecture


## Installation

### Required packages

Make a new virtual env and source it:
```
$ python3 -m venv ./lidar_venv
$ source lidar_venv/bin/activate
```

Install dependencies from `requirements.txt`:
```
$ pip install -r requirements.txt
```
